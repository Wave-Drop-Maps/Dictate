# Sounds

Dictate plays `drop_003` from [Interface Sounds](https://kenney.nl/assets/interface-sounds) by
[Kenney](https://kenney.nl), released under CC0 (public domain). It's been converted to WAV and levelled,
and the same sound is used for each event (`start`, `stop`, `handsfree`, `cancel` and `notice`), so you can
swap in different sounds per event by replacing those files.
