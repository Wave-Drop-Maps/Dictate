# Sounds

Dictate plays a softened version of `drop_003` from [Interface Sounds](https://kenney.nl/assets/interface-sounds) by
[Kenney](https://kenney.nl), released under CC0 (public domain). It has been levelled, filtered to remove the harsh highs, pitched down slightly and given a short soft echo,
and the same sound is used for each event (`start`, `stop`, `handsfree`, `cancel` and `notice`), so you can
swap in different sounds per event by replacing those files.
